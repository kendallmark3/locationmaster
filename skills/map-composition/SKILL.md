# Skill — Map Composition

## Purpose
Reusable rules for producing a readable location story.

## Defaults
- Subject point is visually dominant.
- Labels should avoid unnecessary duplication.
- Keep symbol vocabulary small and consistent.
- Categories are presentation metadata, not geographic truth.
- User overrides always win over AI presentation suggestions.
- Preserve coordinates when changing symbol/label/category.

- company
